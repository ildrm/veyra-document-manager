# Veyra

Veyra is an evidence-first enterprise knowledge and document intelligence platform. This repository contains the production foundation and first vertical slice: secure document ingestion, a permission-aware library and search experience, and grounded answers with exact source citations.

See [docs/getting-started.md](docs/getting-started.md) for local setup and [docs/architecture/README.md](docs/architecture/README.md) for the system design.
